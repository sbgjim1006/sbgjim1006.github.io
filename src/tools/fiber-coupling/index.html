03 / FORMULAS

完整公式與統整

先看模場決定的基準效率，再分別理解對位、角度與 z offset，最後將所有條件帶回完整的高斯光場重疊模型。下列單項簡式的其他偏差皆為零。

01　基準效率：模場是否匹配

各軸的接收半徑由模場直徑換算；兩端在束腰平面、沒有位移及傾斜時，效率只由模場匹配決定。x、y 軸可以有不同尺寸。

wfj = MFDj/2，j ∈ {x, y}η₀ = ∏j=x,y [2wbjwfj/(wbj² + wfj²)]

圓形模場的兩軸相同，因此上式化成平方；模場完全匹配時，理想基準效率為 100%。

η₀,circular = [2wbwf/(wb² + wf²)]²

入射束腰是強度下降到峰值的 1/e² 時的半徑。wb、wf、r、z 與真空波長 λ 在計算內均使用 µm；介質波數由 n 修正。

λµm = λnm/1000，k = 2πn/λµm

02　對位：有號位移與橫向容差

圖中的 r 是沿指定方位 α 的有號位置；幾何距離為其絕對值。這個定義讓同一張圖能從 −10 µm 掃描至 +10 µm。

x = r cosα，y = r sinα，ρ = √(x² + y²) = |r|η(r)/η₀ = exp[−2x²/(wbx² + wfx²) − 2y²/(wby² + wfy²)]

同一圓形模場的簡式

η(r)/η₀ = exp(−r²/w²)

任意方位的橢圓模場

Cr = 2 cos²α/(wbx²+wfx²)　　+ 2 sin²α/(wby²+wfy²)|r|D = √(D/Cr)

容差的 D 使用自然對數；1 dB 與半功率各自有不同門檻。半功率的精確損失約為 3.0103 dB。

D1 dB = ln(10)/10，Dhalf = ln(2)等模場：|r|1 dB ≈ 0.480w；|r|half ≈ 0.833w

03　角度：使用弧度的傾斜損失

θ 是間隙介質中的有號小角度，γ 決定傾斜方位。正負號用於同一方位上的雙向掃描；近軸角度分量沿兩個座標方向分解。

θx = θ cosγ，θy = θ sinγ；θ 以 rad 代入η(θ)/η₀ = exp(−Axθx² − Ayθy²)Aj = (k²/2) · wbj²wfj²/(wbj²+wfj²)

同一圓形模場的簡式

η(θ)/η₀ = exp[−(πnwθ/λ)²]

角度容差

Cθ = Ax cos²γ + Ay sin²γ|θ|D = √(D/Cθ)

角度圖與角度差滑桿均使用弧度；進階方位控制的度數會先轉換。近軸模型要求角度夠小。

θrad = θdegree · π/180；1° ≈ 0.0174533 rad

04　Z offset：束腰與接收面的距離

軸向偏差會同時改變入射光束大小與波前曲率。接收模場假設在接收面具有平坦波前；以下只分析軸向偏差。

Zbj = πnwbj²/λ，Zfj = πnwfj²/λη(z) = ∏j=x,y [2√(ZbjZfj)/√((Zbj+Zfj)²+z²)]

圓形模場：論文 Eq. (6)

η(z) = 4ZbZf/[(Zb+Zf)²+z²]

相同圓形模場

η(z)/η₀ = [1+(z/2ZR)²]−1ZR = πnw²/λ|z|D = 2ZR√(eD−1)

同軸、零傾斜時，正負 z 的效率對稱。橢圓模場的軸向容差以完整兩軸公式求解，不以圓形簡式代替。
