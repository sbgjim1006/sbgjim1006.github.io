r 是位移長度；陣列轉角與節距差會產生不同方向的位移。橢圓模場仍按 x、y 分量計算效率。

核心公式：網站與論文如何對上

在同一平面、沒有傾角與波前曲率，且兩端模場均為圓形時，橫向位移長度 r 的功率耦合效率為：

η(r) = [2wbwf / (wb² + wf²)]² · exp[−2r² / (wb² + wf²)]

r² = x² + y²。這就是 Photonica 的主公式，也是 Wang–Su 論文 Eq. 1–3 的圓對稱特例。圓形模場的單獨位移損失只取決於 r；橢圓模場另以方位 α 決定 x = r cosα、y = r sinα，再將兩軸的重疊效率相乘。

相同圓形模場且 r = z = 0：η(θ)/η(0) = exp[−(πnwθ/λ)²]

θ 是總傾角大小；近軸模型以 θₓ = θ cosγ、θᵧ = θ sinγ 換算分量，因此 θ² = θₓ² + θᵧ²。若兩模場半徑不等，各軸傾角的指數為 −(k²θj²/2)·wbj²wfj²/(wbj²+wfj²)，k=2πn/λ；兩軸相乘得到總效率。

論文 Eq. (6)：η(z) = 4Z₁Z₂ / [(Z₁ + Z₂)² + z²]，Zᵢ = πnwᵢ²/λ

此式要求同軸圓形模場、零傾角，z 為兩束腰的軸向距離；本頁假設接收模場束腰在光纖端面。論文在空氣中令 n = 1。當 w₁ = w₂ = w 時，η(z)/η(0) = [1 + (λz/2πnw²)²]−1；若 w₁ ≠ w₂，z = 0 的效率本身也會低於 100%。

展開含波前曲率的完整計算式

對每一軸 j，在接收面令 zRj=πnwbj²/λ、wj(z)²=wbj²[1+(z/zRj)²]、1/Rj=z/(z²+zRj²)、k=2πn/λ；θ 以弧度代入。

aj = 1/wj(z)² + ik/(2Rj),　bj = 1/wfj²,　sj = aj + bj
ηj = 2/[wj(z)wfj|sj|] · exp[−2βjrj² + 2gjrj − Ajθj²],　η=ηxηy

βj=Re(ajbj/sj)；gj=kθjIm(aj/sj)；Aj=(k²/2)Re(1/sj)。g 項就是曲率、傾角與位移同時存在時的交互作用。此處 rj 為有號軸向分量；控制欄 r 是位移長度。符號採與 Photonica 計算器一致的位移與傾角方向。

情況Photonica／常用簡式與 Wang–Su 論文的關係
橫向位移相同圓形模場：η/η₀ = exp[−r²/w²]；1 dB 位移 = 0.480w = 0.240 MFD。論文 Eq. 1–3 的圓對稱、同一平面特例；兩軸可分別相乘。
軸向間距相同模場：η/η₀ = [1 + (λz/2πnw²)²]−1。論文 Eq. 6 適用於兩個不一定相等的圓形模場；相同模場簡式是 Z₁ = Z₂ 的特例。
相對傾角相同模場、z=0：η/η₀ = exp[−(πnwθ/λ)²]。等同論文 Eq. 4 的平面波前特例；θ 須以弧度代入。
橢圓光束文章主式以圓對稱 w₁、w₂ 表示。論文將 x、y 分開；旋轉對稱成像的最佳效率為 4/(2+m+1/m)，m=wₓ/wᵧ。
偏移＋傾角＋間距文章列個別項；其進階計算器也處理波前曲率和交互項。論文 Eq. 5 有偏移與傾角的交互項。本頁用複數高斯重疊一併求值，不能把各項損失固定相加。

Photonica 文章的範例表把傾角容差列於矽玻璃介質、軸向間距列於空氣；本頁的 n 則同時用於傳播與傾角計算。比較數字時須先設成相同介質。

模型邊界

本頁是理想純量、近軸、單一高斯模場的計算。不含圓柱透鏡的 ABCD 幾何、光柵耦合器繞射與頻譜、非高斯光束、像差、偏振、菲涅耳反射、膠材固化位移或製程統計。論文中的 98.2% 是特定圓柱透鏡設計案例；調整本頁束腰只能研究其輸出模場的重疊，不能宣稱重現該透鏡設計。論文報 3 dB 容差、Photonica 表格主要報 1 dB，比較時須使用同一損失門檻與參考平面。
